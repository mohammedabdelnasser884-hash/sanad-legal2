# دلتا المرحلة 1 — CaseSearchSelect

## الملفات في الدلتا دي

1. **`src/shared/ui/CaseSearchSelect.tsx`** (جديد بالكامل)
   دروب-داون قضية ببحث حي في الداتابيز (db.from('cases'))، بنفس بنية
   ClientSearchSelect.tsx بالحرف. بيرجّع MappedCase كامل (مش id/title بس)
   عشان resolveCaseFeeClient يشتغل فورًا لحظة الاختيار.

2. **`src/hooks/useAppData.ts`** (تعديل بسيط جدًا — سطرين بس)
   إضافة `export` لدالتين كانتا خاصتين بالملف: `mapCaseRow` و
   `fetchPartiesMapByCaseIds`. صفر تغيير في المنطق أو السلوك — بس عشان
   CaseSearchSelect.tsx الجديد يقدر يستخدم نفس منطق تطبيع القضية المستخدم
   في fetchCases/searchCases، بدل ما نبني نسخة تانية من نفس المنطق.

3. **`docs/تقرير-مراجعة-قسم-الأتعاب-29-أغسطس-2026.md`**
   التقرير الكامل بالخطة المرحلية (٨ مراحل) — دي المرحلة 1 منها.

## ملاحظة مهمة

مفيش node_modules ولا اتصال إنترنت متاح عندي في الجلسة دي، فمقدرتش أشغّل
`tsc`/lint فعليًا للتأكيد. راجعت الكود يدويًا (مسارات الـimport، الأنواع)
ومتأكد إنها سليمة منطقيًا، لكن يفضل تشغيل `npm run build`/`tsc --noEmit`
عندك قبل الدمج للتأكد النهائي.
